# Habit Helper Doge — Updating & Cloning Guide

## Update the app on GitHub

Run these commands in your project folder to push changes:

```bash
git status
git add .
git commit -m "Update Habit Helper Doge"
git push origin main
```

## GitHub Pages setup (one-time)

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select **Branch: `main`** and **Folder: `/public`**.
5. Save and wait a few minutes for the site to update.

## Clone the project in Android Studio

1. Open Android Studio.
2. Click **File → New → Project from Version Control**.
3. Paste your GitHub repository URL.
4. Choose a local folder and click **Clone**.
5. When the project opens, you can edit the HTML/CSS/JS files directly.

## Open an existing local clone

1. In Android Studio, click **File → Open**.
2. Select the local `Health-DOGE` folder.
3. Android Studio will load the project files.
